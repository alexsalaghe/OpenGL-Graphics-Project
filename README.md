# Proiect Grafică 3D - Racheta spatiala

Un proiect de grafică pe calculator dezvoltat în limbajul C cu ajutorul bibliotecii **OpenGL**. Aplicația randează o scenă 3D interactivă centrată în jurul modelului unei rachete, implementând elemente fundamentale de grafică precum transformări geometrice, controlul camerei și iluminare.

## 🚀 Caracteristici principale
* **Randare 3D**: Modelarea componentelor rachetei folosind primitive grafice.
* **Control Interactiv**: Cameră mobilă care permite vizualizarea scenei din unghiuri diferite.
* **Sistem de Iluminare**: Setarea surselor de lumină pentru a evidenția geometria obiectelor 3D din scenă.

## 🛠️ Tehnologii utilizate
* **Limbaj**: C
* **API Grafic**: OpenGL
* **IDE**: Microsoft Visual Studio

## 🎮 Controale (Instrucțiuni de utilizare)
* *Notează aici ce taste ai mapat în cod, de exemplu:*
* `W` / `A` / `S` / `D` sau `Săgeți` — Deplasare cameră / Rotire scenă.
* `Click stânga` + `Mouse` — Rotirea camerei în jurul rachetei.
* `Esc` — Închidere aplicație.
